# Полные данные отзывов и вопросов

Текущий опрос получает отзывы и вопросы WB, Яндекс Маркета и Ozon за **последние 7 суток по дате создания**. Дополнительно [загрузка для аналитики](HISTORY.md) получает отзывы за период последних 100 выкупов, максимум на 90 дней назад. Сохраняются все поля API, исходный JSON и время получения; неизвестные дополнительные поля не отбрасываются. Изменения текста сохраняются в истории сообщений. Более старые локальные записи остаются доступны.

## Что видно в карточке

- Отдельные комментарий, достоинства и недостатки.
- Фотографии: миниатюры и открытие полного изображения.
- Видео: встроенный проигрыватель и ссылка для отдельного открытия. Видео WB в HLS могут потребовать Safari; ссылки Маркета могут вести на внешний проигрыватель.
- Дополнительные данные, когда они есть в API: товар, бренд, артикулы, размер, цвет, статус и дата покупки, ID заказа, статистика, баллы за отзыв, рекомендации, теги и связанные отзывы.
- Ответ WB; для Маркета — комментарии к отзыву, ответы на вопросы и вложенные в них комментарии с автором, статусом и прочими исходными полями. Для ответов с датой API сохраняется эта дата; если даты в ответе API нет, время сообщения означает момент получения приложением.
- Раскрываемый блок «Все поля, полученные от маркетплейса» и скачивание JSON с исходным обращением и всей полученной историей. Скачивание доступно в пределах тех же прав компании, что и карточка обращения.

Фото и видео хранятся как ссылки, которые вернул маркетплейс. Файлы не скачиваются на диск Mac автоматически и не входят в резервную копию базы. Для просмотра нужен интернет, ссылки могут истекать. Локальное архивирование файлов и анализ изображений или видео AI в эту поставку не входят; AI по-прежнему получает текст.

## Обновление существующей установки

В прежнем окне Terminal остановите приложение через Ctrl+C. При необходимости сначала сделайте резервную копию:

```bash
.venv/bin/python manage.py backup_db
```

Затем:

```bash
git pull --ff-only
bash start.sh
```

Миграция `0004` добавила поля полных данных; `0008` добавляет отдельные состояния исторического обхода. Обращения, сообщения, пользователи, статусы, исходящая очередь и сроки пауз сохраняются. Текущий опрос WB получает недельное окно крупными страницами. История до 100 выкупов обходит отдельный архив с собственной позицией. Повторная загрузка не создаёт дубликатов и не запускает AI из-за одного изменения фото или статистики.

При текущем опросе Маркет получает отзывы с явными `dateTimeFrom`/`dateTimeTo` за 7 суток. Для вопросов передаются `dateFrom`/`dateTo`, а записи дополнительно проверяются по точному времени: API фильтрует вопросы только с точностью до календарного дня. Текущий опрос не импортирует старые, будущие и недатированные записи. Прямые запросы по ID в фоновой дозагрузке переписки выполняются только для обращений последних 7 суток. Для аналитики отзывы за более ранний период загружаются отдельной очередью. Если запись больше не доступна API, локальная история не удаляется, а повтор откладывается.

Дополнительная история загружается не более чем по 10 обращений недельного окна за завершённый цикл кабинета. Сохраняются страницы комментариев Маркета: после паузы загрузка продолжается с нужной страницы, пока обращение входит в 7 суток. Активные обращения проверяются повторно по очереди примерно через 15 минут, закрытые — через сутки; фактический срок зависит от очереди и лимитов API. Изменение количества комментариев в отзыве Маркета ставит историю на ближайшую проверку. При нулевом количестве комментариев отдельный запрос истории не расходуется.

Проверка публикации уже отправленного оператором ответа сохраняется и за пределами недельного окна. Это адресная проверка результата отправки, а не периодическая загрузка старого архива. Лимиты API соблюдаются и в этом случае.

При первой дозагрузке исторические комментарии не открывают закрытые диалоги заново. Последующие новые сообщения покупателей могут вернуть диалог в статус «Новое».

В «Интеграциях» доступны счётчики «Полные данные за 7 суток» и «История ответов за 7 суток», отдельно показаны общее число обращений и состояния исторического обхода. В карточке видно время получения данных и причину отложенной проверки. Для старых записей указано ограничение фоновой загрузки полной переписки. Паузы API могут замедлить даже недельную загрузку.

## Границы доступности

Сохраняются данные отзывов, вопросов и их ответов в рамках прав API-ключей. Продажи WB и Маркета подключаются отдельно; чаты пока не подключены. Некоторые сведения из кабинетов продавцов API не возвращают. Доступность удалённых отзывов и медиассылок определяется площадкой. Автоматическая историческая загрузка отзывов ограничена 90 днями; полная переписка текущих обращений — недельным окном. Новые записи после начала обхода войдут в следующий цикл.

Контракты Маркета сверены с официальными схемами [GoodsFeedbackDTO](https://github.com/yandex-market/yandex-market-partner-api/blob/main/openapi/components/schemas/GoodsFeedbackDTO.yaml), [GoodsFeedbackMediaDTO](https://github.com/yandex-market/yandex-market-partner-api/blob/main/openapi/components/schemas/GoodsFeedbackMediaDTO.yaml), [AnswerDTO](https://github.com/yandex-market/yandex-market-partner-api/blob/main/openapi/components/schemas/AnswerDTO.yaml). Контракты WB сверены с моделями публичного SDK `wildberries-sdk@0.1.174` для раздела «Общение с покупателями»: `photoLinks`, `video`, `productDetails`, `answer` и остальные поля отзыва сохраняются в исходном виде.

Для Ozon медиа догружаются из v2/review/info, ответы и комментарии — отдельными страницами. [Подключение и ограничения](OZON.md).
