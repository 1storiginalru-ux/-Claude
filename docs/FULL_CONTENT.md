# Полные данные отзывов и вопросов

Приложение сохраняет все поля отдельного отзыва или вопроса, которые возвращает API Wildberries или Яндекс Маркета. Исходные данные хранятся целиком в JSON вместе со временем получения; неизвестные приложению дополнительные поля не отбрасываются. При повторной загрузке сохраняется актуальная версия данных. Изменения текста продолжают сохраняться в истории сообщений.

## Что видно в карточке

- Отдельные комментарий, достоинства и недостатки.
- Фотографии: миниатюры и открытие полного изображения.
- Видео: встроенный проигрыватель и ссылка для отдельного открытия. Видео WB в HLS могут потребовать Safari; ссылки Маркета могут вести на внешний проигрыватель.
- Дополнительные данные, когда они есть в API: товар, бренд, артикулы, размер, цвет, статус и дата покупки, ID заказа, статистика, баллы за отзыв, рекомендации, теги и связанные отзывы.
- Ответ WB; для Маркета — комментарии к отзыву, ответы на вопросы и вложенные в них комментарии с автором, статусом и прочими исходными полями. Для ответов с датой API сохраняется эта дата; если даты в ответе API нет, время сообщения означает момент получения приложением.
- Раскрываемый блок «Все поля, полученные от маркетплейса» и скачивание JSON с исходным обращением и всей полученной историей. Скачивание доступно в пределах тех же прав компании, что и карточка обращения.

Фото и видео хранятся как ссылки, которые вернул маркетплейс. Файлы не скачиваются на диск Mac автоматически и не входят в резервную копию базы. Для просмотра нужен интернет, ссылки могут истекать. Локальное архивирование файлов и анализ изображений или видео AI в эту поставку не входят; AI по-прежнему получает текст.

## Обновление существующей установки

В прежнем окне Terminal остановите приложение через Ctrl+C. При необходимости сначала сделайте резервную копию:

```bash
.venv/bin/python manage.py backup_db
```

Затем:

```bash
git pull --ff-only
bash start.sh
```

Миграция `0004` добавляет поля, сохраняя обращения, сообщения, пользователей, статусы и исходящую очередь. Позиция обхода WB один раз сбрасывается для повторного чтения архива крупными страницами: так полные данные прежних отзывов загружаются без отдельного запроса на каждый из них. Сроки пауз и общий бюджет WB сохраняются; повторная загрузка не создаёт дубликатов и не запускает AI из-за одного изменения фото или статистики.

Маркет дополняет данные во время обычного опроса. Для уже известных обращений вне текущего временного окна приложение также пробует получить запись по ID. Если запись больше не доступна API, имеющаяся локальная история не удаляется, а повтор откладывается.

Дополнительная история и оставшиеся старые записи загружаются не более чем по 10 обращений за завершённый цикл кабинета. Сохраняются страницы комментариев Маркета: после паузы загрузка продолжается с нужной страницы. Новые и активные обращения проверяются повторно по очереди примерно через 15 минут, старые — через сутки; фактический срок зависит от очереди и лимитов API. Изменение количества комментариев в отзыве Маркета ставит историю на ближайшую проверку. При нулевом количестве комментариев отдельный запрос истории не расходуется.

При первой дозагрузке исторические комментарии не открывают закрытые диалоги заново. Последующие новые сообщения покупателей могут вернуть диалог в статус «Новое».

В «Интеграциях» доступны счётчики «Полные данные обращений» и «История ответов получена». В карточке видно время получения данных и причину отложенной проверки. Первоначальная дозагрузка может идти долго из-за лимитов WB; оставьте программу запущенной.

## Границы доступности

Сохраняются данные отзывов, вопросов и их ответов в рамках прав текущих API-ключей. Это не подключение всех API заказов, продаж, чатов и возвратов. Некоторые сведения из кабинетов продавцов API не возвращают. Доступность удалённых отзывов, медиассылок и глубина истории определяются площадкой. Обычный запрос Маркета охватывает отзывы за 6 месяцев и вопросы за 1 месяц; неизвестная более ранняя история автоматически по всем периодам не сканируется.

Контракты Маркета сверены с официальными схемами [GoodsFeedbackDTO](https://github.com/yandex-market/yandex-market-partner-api/blob/main/openapi/components/schemas/GoodsFeedbackDTO.yaml), [GoodsFeedbackMediaDTO](https://github.com/yandex-market/yandex-market-partner-api/blob/main/openapi/components/schemas/GoodsFeedbackMediaDTO.yaml), [AnswerDTO](https://github.com/yandex-market/yandex-market-partner-api/blob/main/openapi/components/schemas/AnswerDTO.yaml). Контракты WB сверены с моделями публичного SDK `wildberries-sdk@0.1.174` для раздела «Общение с покупателями»: `photoLinks`, `video`, `productDetails`, `answer` и остальные поля отзыва сохраняются в исходном виде.
