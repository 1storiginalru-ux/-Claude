# Запуск на Mac

Программа работает на вашем Mac. Вы запускаете её через Terminal, а пользуетесь интерфейсом в браузере. Отдельный сервер для этого не нужен.

## Один раз перед первым запуском

Установите **Python 3.12 или новее** с [официального сайта Python](https://www.python.org/downloads/macos/). Если он уже установлен, повторять установку не нужно. После установки закройте и снова откройте Terminal.

## Скачать с GitHub и запустить

Откройте **Terminal** и выполните по очереди:

```bash
git clone https://github.com/1storiginalru-ux/-Claude.git voice-mvp
cd voice-mvp
bash start.sh
```

Если Mac предложит установить инструменты разработчика для команды `git`, согласитесь, дождитесь установки и повторите первую команду. Для закрытого репозитория GitHub понадобится вход в аккаунт, которому выдали доступ.

При первом запуске скрипт сам установит библиотеки и подготовит базу. Когда появится запрос, придумайте логин и пароль. Пароль вводится без отображения символов. Дождитесь открытия браузера и войдите с этим логином и паролем.

Если браузер не открылся, введите в его адресной строке локальный адрес программы: `http://127.0.0.1:8000`. Это адрес приложения на вашем Mac; он работает только пока программа запущена.

В первый раз появятся демонстрационные обращения. Они не связаны с реальными клиентами. Для WB, Яндекс Маркета и AI затем нужно отдельно подключить свои кабинеты и ключи.

## Повторный запуск

В Terminal перейдите в ту же папку и запустите:

```bash
cd voice-mvp
bash start.sh
```

Если папка сохранена в другом месте, сначала откройте именно её в Terminal. Повторно скачивать программу и создавать пользователя не нужно. Данные сохраняются в папке `.local` внутри программы; не удаляйте её.

**Остановка:** нажмите **Ctrl+C** в окне Terminal. Закрытие вкладки браузера программу не останавливает.

## Скачать без команды git

На странице репозитория нажмите **Code → Download ZIP**, распакуйте архив. Откройте распакованную папку в Terminal и выполните `bash start.sh`. Остальные шаги те же.

## Обновить программу

Остановите её через Ctrl+C. Если скачивали через `git clone`, в папке программы выполните:

```bash
git pull --ff-only
bash start.sh
```

При изменении списка библиотек скрипт обновит их, а изменения базы применит сам. Ваши данные и учётная запись сохраняются. Перед обновлением с рабочими данными сделайте копию базы командой `.venv/bin/python manage.py backup_db`.

## Если возникла ошибка

- **«Нужен Python 3.12»** — установите актуальный Python с сайта выше и заново откройте Terminal.
- **«Порт 8000 занят»** — найдите прежнее окно программы и остановите его через Ctrl+C. Либо запустите на другом порту: `bash start.sh --port 8001`.
- **Ошибка загрузки библиотек** — проверьте интернет и повторите `bash start.sh`. Проверку сертификатов отключать не нужно.
- **Забыли пароль** — в папке программы выполните `.venv/bin/python manage.py changepassword ВАШ_ЛОГИН`.

Для разработчиков: `bash start.sh --setup-only --no-input` готовит окружение без открытия браузера и без запроса пользователя; `--no-browser` отключает автоматическое открытие браузера. В этой поставке поддерживается локальный запуск; промышленное размещение и реальные подключения принимаются отдельно.
