# Проверки текущей облачной среды

Проверено 21 октября 2026 года, Python 3.12, Django 5.2.18.

- `manage.py test desk.tests`: 63 теста, все прошли, пропущенных и ожидаемых падений нет. Исходящие HTTP-запросы в тестах блокируются; адаптеры проверяются на контролируемых ответах.
- `manage.py check`: ошибок нет.
- `manage.py makemigrations --check --dry-run`: незаписанных изменений схемы нет.
- `pip check`: конфликтов зависимостей нет.
- `scripts/setup.sh`: проверен повторный запуск на уже установленной среде; миграции и проверка завершились успешно.
- `run_dev`: HTTP, worker и polling запущены, остановлены через родительский процесс и повторно запущены.
- Реальный локальный HTTP: `/health/` проверил доступ к БД; вход с CSRF и сессионной cookie прошёл; 9 страниц приложения после входа вернули ожидаемое содержимое; CSS/JavaScript доступны. Временный пользователь проверки и его сессия удалены.
- `worker --once` и `sync_channels`: завершились без исходящих сообщений и без включённых реальных кабинетов. Это проверка команд, не проверка внешних API.
- `seed_demo`: повторный запуск сохранил 1 демо-компанию, 2 выключенных кабинета, 3 товара, 12 обращений и 4 расследования без дублей.
- `calculate_baselines`: на короткой демо-истории новые исторические baseline не созданы, поскольку недостаточно истории. Расчёт на достаточной истории проверен отдельными тестами.
- `backup_db`: создана локальная согласованная копия SQLite. Восстановление production-резервной копии не проверялось.

Установлены и зафиксированы зависимости. Процессы и `.local/` относятся к текущему экземпляру, исходники созданы в локальном checkout. При первоначальной проверке файлы были только локальными. Для поставки через GitHub добавлены `start.sh`, переносимый установщик и инструкция `docs/MAC.md`. Workflow CI настроен для Linux и macOS; его выполнение на GitHub в текущей машине не проверено.

В конфигурационный черновик сохранены `install_script`, `start_skill` и требования к `VOC_WB_TOKEN`, `VOC_YM_TOKEN`, `VOC_AI_KEY`. Для них добавлены домены `feedbacks-api.wildberries.ru`, `api.partner.market.yandex.ru`, `api.openai.com`, `api.anthropic.com`; существующие пакетные сетевые разрешения сохранены. Значения ключей не сохранены. Публикация среды и восстановление в новой задаче не выполнялись.

В приложении пока нет постоянных пользователей: нужен собственный `createsuperuser` по README. Реальная публикация ответов WB/Яндекс Маркета и ответы настоящей AI-модели остаются непроверенными до настройки ключей и кабинетов. Подключение Bitrix24 отложено по выбору пользователя. Приёмка внешних подключений описана в `docs/acceptance.md`.


## Поставка для локального запуска на Mac

- `bash start.sh --setup-only --no-input`: проверена установка с нуля в новую `.venv` и отдельную пустую базу, без использования облачного пути `/workspace/.venvs/customer-voice`.
- Повторная подготовка пропустила переустановку библиотек, сохранила 3 товара и 12 демо-обращений без дублей.
- Запуск через `bash start.sh --no-input --no-browser --port 18080`: проверены HTTP readiness, вход с паролем и CSRF, Inbox и CSS. После завершения установщика сервер остановился.
- Отдельные тесты проверяют, что существующие компании и пользователи не заменяются и общий пароль не создаётся.
- Проверки выполнены в Linux. Запуск на физическом Mac здесь не выполнялся; для этого в CI предусмотрен `macos-latest`.
