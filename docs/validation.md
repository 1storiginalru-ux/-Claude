- При поставке запуска на Mac: `manage.py test desk.tests` — 63 теста, все прошли. Исходящие HTTP-запросы в тестах блокируются; адаптеры проверяются на контролируемых ответах.
- `manage.py check`: ошибок нет.

- `pip check`: конфликтов зависимостей нет.
- `scripts/setup.sh`: проверен повторный запуск на уже установленной среде; миграции и проверка завершились успешно.
- `run_dev`: HTTP, worker и polling запущены, остановлены через родительский процесс и повторно запущены.

- `worker --once` и `sync_channels`: завершились без исходящих сообщений и без включённых реальных кабинетов. Это проверка команд, не проверка внешних API.

Установлены и зафиксированы зависимости. Процессы и `.local/` относятся к текущему экземпляру, исходники созданы в локальном checkout. При первоначальной проверке файлы были только локальными. Для поставки через GitHub добавлены `start.sh`, переносимый установщик и инструкция `docs/MAC.md`. Workflow CI настроен для Linux и macOS; его выполнение на GitHub в текущей машине не проверено.

В конфигурационный черновик сохранены `install_script`, `start_skill` и требования к `VOC_WB_TOKEN`, `VOC_YM_TOKEN`, `VOC_AI_KEY`. Для них добавлены домены `feedbacks-api.wildberries.ru`, `api.partner.market.yandex.ru`, `api.openai.com`, `api.anthropic.com`; существующие пакетные сетевые разрешения сохранены. В приложении пока нет постоянных пользователей: нужен собственный `createsuperuser` по README. Реальная публикация ответов WB/Яндекс Маркета и ответы настоящей AI-модели остаются непроверенными до настройки ключей и кабинетов. Подключение Bitrix24 отложено по выбору пользователя. ## Поставка для локального запуска на Mac

- `bash start.sh --setup-only --no-input`: проверена установка с нуля в новую `.venv` и отдельную пустую базу, без использования облачного пути `/workspace/.venvs/customer-voice`.
- Повторная подготовка пропустила переустановку библиотек, сохранила 3 товара и 12 демо-обращений без дублей.
- Запуск через `bash start.sh --no-input --no-browser --port 18080`: проверены HTTP readiness, вход с паролем и CSRF, Inbox и CSS. После завершения установщика сервер остановился.
- Отдельные тесты проверяют, что существующие компании и пользователи не заменяются и общий пароль не создаётся.
- Проверки выполнены в Linux. Запуск на физическом Mac здесь не выполнялся; для этого в CI предусмотрен `macos-latest`.

## Исправление ограничения частоты Wildberries

- Полный набор: **77 тестов прошли**. Добавлены 14 проверок HTTP 429, заголовков лимита, общего бюджета, продолжения загрузки и очереди ответов.
- Проверено сохранение паузы 720 секунд и чтение этой паузы отдельным процессом: новый процесс не отправляет запрос до разрешённого времени.
- После HTTP 429 загрузка продолжает сохранённую страницу с прежней временной границей. Прерванная страница может быть получена повторно без дублей сообщений.
- Проверено подтверждение публикаций перед загрузкой архива и сохранение ответов в Queued при лимите. Локальное ожидание бюджета не расходует попытки отправки.
- SIGTERM завершает polling и освобождает блокировку синхронизации; пауза API и позиция загрузки остаются в БД.
- Применена миграция `0003`: созданы служебные таблицы ограничения частоты и позиции загрузки, в журнал добавлено время повторной попытки. Исходные таблицы обращений и кабинетов не пересоздаются.
- Проверки выполнены на контролируемых ответах HTTP и отдельных локальных процессах. Реальная синхронизация WB остаётся для проверки на Mac пользователя.

## Диагностика повторного HTTP 429

- `diagnose_wb` показывает локальный этап и количество обращений без сети. Флаг `--probe` разрешает один GET с `take=1`, соблюдая сохранённую паузу и блокировку синхронизации.
- Шесть дополнительных тестов проверяют отсутствие запросов по умолчанию и во время паузы, выбор кабинета, неизменность курсора и обращений, вывод заголовков лимита и скрытие ключа даже при его отражении в ошибке сервера.
- Полный набор: **83 теста прошли**; `check`, проверка миграций и `git diff --check` прошли. Реальная причина ответов WB на Mac пока не установлена; для неё нужен результат диагностики пользователя.
