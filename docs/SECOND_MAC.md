# Установка на другом Mac

Последняя версия находится в ветке `main` на [GitHub](https://github.com/1storiginalru-ux/-Claude). При скачивании через `git clone` вы получите актуальную версию, включая исправления лимитов WB и блокировок локальной базы.

Программа хранит данные на каждом компьютере отдельно. Скачивание исходников не переносит прежние отзывы, кабинеты и логин. Чтобы продолжить работу с ними, перенесите папку данных по шагу 3 **до первого запуска**.

## 1. Подготовить новый Mac

Установите Python 3.13 или 3.14 с [официального сайта Python для macOS](https://www.python.org/downloads/macos/). Версия 3.12 тоже поддерживается. После установки откройте новое окно Terminal.

Выполните:

```bash
git --version
```

Если Mac предложит установить Command Line Tools, согласитесь и дождитесь окончания. Полный Xcode не требуется. Затем повторите `git --version`: должен появиться номер версии Git.

## 2. Скачать программу

В Terminal выполните по очереди:

```bash
cd ~
git clone https://github.com/1storiginalru-ux/-Claude.git voice-mvp
cd voice-mvp
```

Программа будет в вашей домашней папке `voice-mvp`. Если папка уже существует, не удаляйте её: откройте её через `cd ~/voice-mvp` и обновите командой `git pull --ff-only`.

## 3. Перенести прежние данные, если они нужны

На старом Mac:

1. Остановите программу через Ctrl+C. Остановите также отдельные запуски worker или синхронизации, если запускали их вручную.
2. Откройте папку старой программы в Finder.
3. Нажмите **Command + Shift + .** (точка), чтобы показать скрытые файлы.
4. Скопируйте **всю папку `.local`** на новый Mac, например через AirDrop или внешний накопитель. Она содержит базу, пользователей, настройки и служебный ключ приложения. Передавайте её напрямую между своими устройствами.

На новом Mac откройте домашнюю папку в Finder (**Shift + Command + H**), затем `voice-mvp`. Поместите перенесённую `.local` внутрь этой папки, рядом со `start.sh`.

Если в новой папке уже есть `.local` с нужными данными, не заменяйте её: это две разные базы, автоматического объединения нет. Для новой установки из шага 2 папки `.local` ещё не будет.

Папку `.venv` переносить не нужно: библиотеки установятся заново для нового Mac. API-ключи, введённые в Terminal старого компьютера, нужно ввести заново по шагу 4. Если на старом компьютере использовали `VOC_STATE_DIR`, переносите данные из указанной там папки.

При переносе продолжайте работу с этой базой на новом Mac, оставив старый экземпляр остановленным. Копии базы на двух компьютерах не синхронизируются; в них также скопирована исходящая очередь.

Если перенос не нужен, пропустите этот шаг: первый запуск создаст новую базу с демо-данными.

## 4. Ввести ключи в новом Terminal

Для каждого используемого подключения выполните команду `read` отдельно, затем вставьте соответствующий ключ и нажмите Enter. Символы ключа отображаться не будут. Только после ввода ключа выполняйте команду `export`.

Wildberries:

```bash
read -s VOC_WB_TOKEN
```

После вставки ключа и Enter:

```bash
export VOC_WB_TOKEN
```

Яндекс Маркет:

```bash
read -s VOC_YM_TOKEN
```

После вставки ключа и Enter:

```bash
export VOC_YM_TOKEN
```

Если AI уже настроен в компании, аналогично введите его ключ:

```bash
read -s VOC_AI_KEY
```

После вставки ключа и Enter:

```bash
export VOC_AI_KEY
```

Ключи не нужно помещать в исходники или присылать в чат. Для собственных имён переменных используйте имена из настроек кабинетов и компаний. Эти переменные доступны только в текущем окне Terminal и запущенным из него процессам; `.env` автоматически не читается.

## 5. Запустить

В том же окне Terminal, находясь в папке `voice-mvp`, выполните:

```bash
bash start.sh
```

Скрипт установит зависимости и обновит схему базы с сохранением записей. Если данные перенесены, войдите с прежним логином и паролем. Если база новая, создайте логин и пароль при запросе в Terminal.

Откроется браузер. Если он не открылся, введите `http://127.0.0.1:8000`. Для остановки программы нажмите Ctrl+C в Terminal.

При новой базе создайте реальную компанию (без отметки «Демонстрационная компания») и кабинеты:

| Поле | Wildberries | Яндекс Маркет |
|---|---|---|
| Platform | Wildberries | Яндекс Маркет |
| Имя переменной с API-ключом | `VOC_WB_TOKEN` | `VOC_YM_TOKEN` |
| Business ID | Пусто | Числовой ID бизнеса |
| Enabled | Включено | Включено |

При перенесённой базе заново создавать эти кабинеты не нужно. Откройте «Интеграции» и проверьте загрузку. Паузы WB переносятся вместе с базой. Автоматическая загрузка и дополнение ограничены последними 7 сутками; прежняя позиция полного архива переключится на этот период. Старые сохранённые записи остаются доступны.

Для AI в настройках реальной компании должны быть выбраны провайдер, доступная модель и имя переменной `VOC_AI_KEY`, а также заполнены правила общения. Сам ключ без этих настроек не включает AI. На существующем отзыве можно проверить кнопку «AI-анализ и черновик». Новые обращения анализируются при загрузке; публикацию ответа подтверждает оператор.

## Следующие запуски и обновления

Откройте Terminal, выполните `cd ~/voice-mvp`, введите нужные ключи по шагу 4 и запустите `bash start.sh`. Пока вы пользуетесь тем же окном Terminal, повторно вводить ключи не требуется.

Для обновления остановите программу через Ctrl+C, выполните `git pull --ff-only`, затем `bash start.sh`. Подробные решения ошибок приведены в [инструкции для Mac](MAC.md).
